Data & privacy

On this device

CashTrack stores records locally in this browser using IndexedDB. No account or cloud sync is required. Clearing browser data or uninstalling the browser can erase records. Export backups regularly.

Install CashTrack

On Android, open the hosted HTTPS app in Chrome, then tap ⋮ → Install app or Add to Home screen. Installation and offline caching require HTTPS (or localhost). For offline updates, reopen the app online occasionally.
